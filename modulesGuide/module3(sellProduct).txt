# 3.0 MARKET & SELL: Enterprise Guide

Maine CPQ, TPM/RGM, CDP, RevOps, pricing optimization aur order management ke best practices dekh ke ye design kiya hai. Pehle estimate 21 screens / 100 tabs ka tha, par chart ke saare nodes cover karne ke liye final **24 screens / 115 tabs** ho gaye (end mein node → screen/tab map hai).

# COMMON FOUNDATION (sab modules pe lagu)

**Common rules:** API prefix `/api/mns/...`. Har create/edit/action `audit_log` mein jayega. Har master `effective_from/effective_to` aur `status[draft/active/disabled]` ke saath (delete nahi, disable). Har table mein `entity_id` (multi-company/brand). Policy, rate, threshold, formula aur scoring weights **config tables** mein, hardcode nahi.

**Enterprise rules:**
- **Effective-dating + as-of reports:** price, segment, territory, channel, quota sab effective-dated. Koi bhi report "as-of date" se chalti hai.
- **Multi-currency, multi-language, multi-country:** amount ke saath currency code, reports mein base-currency conversion (`spot/budget/average` rate). Customer-facing text `translations` se.
- **Consent-aware activation:** koi bhi marketing/personalization action pehle `consent_records` check karega (channel + purpose wise). Country config se allowed data aur retention.
- **Explainable AI:** har model score/forecast/recommendation ke saath `model_version`, input snapshot, top drivers. Human override allowed, override reason logged.
- **Event-driven:** har state change `domain_events` (outbox) mein jata hai. Dusre modules subscribe karte hain, direct table access nahi.
- **Scenario + versioning:** plans, budgets, price lists, forecasts sab versioned, baseline lock, aur what-if copy.
- **Approval Engine:** parallel/conditional steps, delegation, SLA escalation, send-back, rescind, fallback approver.
- **Scoped access:** row-level scope by territory/BU/brand/account, aur sensitive field masking.
- **Idempotent bulk APIs:** import/export (CSV/API), `idempotency_key`, partial-failure report.

### Core Logic

5. Capability gap cost approved opportunity ke budget mein auto-add (Module 11).
6. Validation fail par stop ya pivot decision zaroori, reason code ke saath.

# RESEARCH BASIS

- EAM poore lifecycle (capex se decommissioning tak) ko cover karta hai jabki CMMS work-order-centric aur narrow hota hai, isiliye ye guide CMMS nahi, poora EAM bana hai.
- Maximo jaise platforms mein Health, Predict, Visual Inspection aur Mobile alag modules hain, isi wajah se Screen 9 (health/predict), Screen 11 (signals/mobile) aur Screen 16 (IoT/mobile) alag diye.
- ISO 55001 documented Strategic Asset Management Plan mandatory karta hai, aur second edition July 2024 mein publish hua; isse Screen 16 tab 3 aur `am_plans` aaye.
- Capital tools stage-gate, EAC forecasting aur SAP/P6 se earned value (CPI/SPI) use karte hain, Screen 5 isi pe based hai.
- IWMS mein lease accounting (ASC 842/IFRS) space aur maintenance ke saath integrated hota hai, isse Screen 2 tab 6 aur Screen 3 tab 3 bane.
- RCM findings ko CMMS mein PM trigger, condition alert aur spare reorder point banna chahiye warna analysis bekar rehta hai; Screen 9 logic point 1 yahi karta hai.
- Failure code capture ISO 14224-aligned library se closure par enforce karna reliability data banata hai, Screen 10 tab 4 aur Screen 11 tab 6.
- ASC 410-20 ke under ARO ka liability fair value par recognize hota hai, Screen 12 tab 3 isi pe hai.

Regulation ke specific numbers (thresholds, retention years, waste codes, UN classes) maine config tables mein rakhe hain, har country ke legal/EHS team se verify karke bharna.
